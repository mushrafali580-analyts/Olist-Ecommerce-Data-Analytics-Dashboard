# Olist Ecommerce Data Analytics Dashboard (Group Project)

## Project Preview
![Overall Analysis](./overall_analysis.png)

## Project Overview
An end-to-end collaborative group project analyzing the Olist Ecommerce dataset. This multi-page interactive dashboard provides comprehensive insights into sales trends, customer behavior, and payment methods to drive data-backed business decisions.

> 📝 *Note:* Due to GitHub's file size limit for direct uploads, the main Power BI file is uploaded as a .pbit (Template). You can open it in Power BI Desktop to load the complete structure.

## Tech Stack Used
* *BI & Data Visualization:* Power BI Desktop
* *Data Modeling & ETL:* Power Query (Advanced Transformations & Merging)
* *Calculations:* DAX (Custom Measures for Sales, Order Volatility, and Customer Growth)

## Key Pages & Insights Covered

### 1. Overall Analysis
* *High-Level KPIs:* Tracking Total Sales ($13.59M), Total Orders (96K), and Average Rating (3.84).
* *Trend Analysis:* Visualizing orders by Year, Quarter, and Month alongside customer state distributions.

### 2. Revenue Analysis
![Revenue Analysis](./revenue_analysis.png)
* Deep dive into profitability, monthly revenue growth trajectories, and yearly performance comparison.

### 3. Pet Shop Analysis
![Pet Shop Analysis](./pet_shop_analysis.png)
* Domain-specific breakdown analyzing performance, order volumes, and sales in high-growth product categories.

### 4. Payment Analysis
![Payment Analysis](./payment_analysis.png)
* Detailed breakdown of customer preferences across different payment channels including Credit Card, Boleto, and Vouchers.
